# Booking security view — from planning to day

On <LIV code="personWorkingLocation:booking-security-day" />, start in **planning mode**, open a **day**, and show the **colored floor plan** when **exactly one** floor is filtered.

<CloudinaryAsset publicId="help/changelog/v3.5.25/booking-security-day-view-en" kind="video" asGif width={640} gifFps={8} alt="Booking security view: from planning to day with colored floor plan" />

## Prerequisites

- The <LIV code="personWorkingLocation:booking-security-day" /> view is assigned to your role.
- People **with** a security profile have booked on the horizon / day in scope.
- For the plan: filter **exactly one** floor.

## Steps

1. **Open the booking security view**  
   Starting point: working locations → <LIV code="personWorkingLocation:booking-security-day" /> in **planning mode** (multi-day horizon), with useful filters (building, one floor, profile).

2. **Click Open detail for the day**  
   Switches to **day mode**: the date and filters stay aligned with the page address.

3. **Read the colored floor plan**  
   With **one** floor selected, the plan appears and is colored by the security profile of that day’s **bookers**.

## Gestures without narration

- Browse planning blocks (floor / zone → profile → cards) before opening a day.
- If no floor or several floors are selected in day mode, only **lists / cards** remain; a message explains how to show the plan.

## Limits

- People **without** a security profile are out of scope for this view.
- No plan in planning mode; no stacked plans; no 3D.
- This is not **assignment** compliance, and not Booking maps.
