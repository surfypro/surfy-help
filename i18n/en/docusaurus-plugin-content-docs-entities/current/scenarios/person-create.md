# Create a person

From the **platform home page**, create a colleague via **Collaborators** → **People** → **Create**, then enter first name and last name.

<CloudinaryAsset publicId="help/changelog/v3.5.21/person-create-en" kind="video" asGif width={640} gifFps={8} alt="Creating a person from the menu" />

## Steps

1. **Open the platform home page**  
   Scenario starting point: tenant home (main menu visible).

2. **Click on the Collaborators menu**  
   Opens the main HR menu.

3. **Click on the People menu**  
   Opens the people list and related actions.

4. **Click on the Create a person menu**  
   Opens the creation form.

5. **Enter the First name**  
   *The person’s first name*

6. **Enter the Last name**  
   *The person’s last name*

7. **Click on the Validate creation button**  
   Saves the person and opens their record.
